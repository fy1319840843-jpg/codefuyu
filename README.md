# codefuyu

## 考研英语真题词汇

预定在线地址：https://fy1319840843-jpg.github.io/codefuyu/

截至 2026-11-14，仓库网页文件已同步，但该在线地址仍返回 404；需要完成下方 GitHub Pages 发布配置后才能在线使用。

按年份和阅读篇章整理的英语一词汇学习网页，支持搜索、篇章筛选、列表与卡片模式、遮住释义、标记已掌握和查看多次出现的词汇。

当前收录 729 条词汇记录、61 个篇章分组（2026-11-14 更新）。原文词形、原形、音标、词性及中英文释义保留在页面中。

### 使用与更新

- 打开在线网址即可使用，无需下载 HTML 文件。
- “已掌握”状态保存在当前浏览器的 localStorage；不同设备、浏览器以及本地文件与在线版之间不会自动同步学习进度。
- 更新词汇时，将更新后的完整网页上传为仓库根目录的 `index.html`。GitHub Pages 发布完成后刷新在线网页即可看到新内容。
- 本地文件的修改不会自动上传到 GitHub，需要提交新版本。

### 发布配置

GitHub 仓库 Settings → Pages → Deploy from a branch → `main` / `(root)`。

页面为独立 HTML 文件，没有构建步骤或外部脚本依赖。`.nojekyll` 用于直接发布静态文件。
